 📊 Manufacturing Metrics & Rejection Analysis – Power BI

An end-to-end Power BI business intelligence dashboard designed
to analyze manufacturing performance, production metrics,
product value, and rejection patterns.

 Project Overview

This project is an interactive Power BI analytics solution
developed to provide insights into manufacturing operations.

The dashboard combines production, product, department,
machine, and rejection-related data to help understand
manufacturing performance and identify areas requiring
operational attention.

---

🎯 Project Objectives

- Monitor overall manufacturing performance
- Analyze production quantity
- Analyze product-wise performance
- Track manufacturing value
- Identify rejection and wastage patterns
- Compare department performance
- Analyze machine-wise rejection
- Provide interactive business insights
